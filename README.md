# CRM B2B

API REST de um **CRM B2B** para gerenciamento do ciclo comercial, desenvolvida com **C# e ASP.NET Core**.

> Projeto em desenvolvimento.

## Funcionalidades

* Autenticação e autorização com JWT e RBAC
* Gestão de usuários
* CRUD de clientes
* CRUD de contatos
* Gestão de leads
* Validações e regras de negócio
* Tratamento centralizado de exceções

## Tecnologias

* C#
* ASP.NET Core Web API
* Entity Framework Core
* PostgreSQL
* LINQ
* JWT
* Swagger / OpenAPI
* Docker

## Fluxo do produto

```text
Lead → Oportunidade → Cliente → Contrato → Financeiro
```

O projeto tem como objetivo aplicar conceitos de **C#/.NET, APIs REST, Entity Framework, banco de dados, segurança e regras de negócio** em uma aplicação B2B próxima de um cenário real.
